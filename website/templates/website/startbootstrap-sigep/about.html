Sistema Integrado de
Gestão de Pedidos

Uma solução web responsiva para digitalizar e estruturar o fluxo de pedidos comerciais entre representantes de vendas e empresas, desenvolvida com Python, Django e arquitetura MVT.

Visão Geral

O que é o SIGEP?

O SIGEP propõe substituir processos manuais e informais de registro de pedidos — como planilhas e aplicativos de mensagens — por uma plataforma web integrada. O sistema organiza todo o ciclo de vida do pedido, desde o cadastro de produtos até a aprovação final pelo gerente.

Desenvolvido como pesquisa aplicada no curso de Bacharelado em Engenharia de Software do IFPR, o projeto foi validado em quatro empresas que operam com representantes comerciais.

Cadastro de empresas, usuários e produtos
Registro e gerenciamento de pedidos de entrada e saída
Controle automático de estoque
Controle de permissões por perfil de usuário
Registro do ciclo de vida do pedido
Notificações automatizadas por e-mail

O Problema

Muitas empresas ainda controlam pedidos de forma manual — cadernos, planilhas, mensagens informais. Esse modelo gera falta de padronização, erros de cálculo, inconsistências no estoque, falhas de comunicação entre representantes e gestores, e baixa rastreabilidade do histórico de operações.

Como desenvolver um sistema web que permita a gestão integrada de pedidos, garantindo organização, controle de estoque, rastreabilidade e confiabilidade?

A Justificativa

Sob a perspectiva acadêmica, o projeto aplica conceitos centrais da Engenharia de Software: levantamento de requisitos, modelagem UML, regras de negócio e arquitetura MVT. Do ponto de vista prático, resolve problemas concretos em empresas comerciais, reduzindo erros operacionais e aumentando a agilidade no processo de vendas.

O SIGEP foi validado em quatro empresas com operação real de representantes comerciais, demonstrando potencial de impacto mensurável na eficiência dos processos.

Stack Técnica

Arquitetura e Tecnologias

Template HTML5 · CSS3 · Bootstrap 5 · Manrope Camada de apresentação — responsiva para web e mobile
View Django · Python · Class-Based Views · Crispy Forms Lógica de controle, regras de negócio e roteamento HTTP
Model Django ORM · PostgreSQL · Neon Cloud Persistência de dados com integridade transacional (ACID)
Python + Django
Framework MVT de alto nível com ORM, autenticação e painel admin nativos. Princípio DRY aplicado ao longo do projeto.
Bootstrap 5
Sistema de grid responsivo e componentes visuais pré-construídos, garantindo usabilidade em desktops e dispositivos móveis.
PostgreSQL (Neon)
Banco relacional com suporte a transações ACID, hospedado em nuvem. Garante integridade referencial entre entidades do sistema.
Google Cloud Platform
Hospedagem em nuvem com alta disponibilidade, acesso remoto e escalabilidade, eliminando a necessidade de servidores físicos.
Git + GitHub
Controle de versão distribuído para rastreamento de alterações, histórico de desenvolvimento e organização das entregas.
Processo

Metodologia de Desenvolvimento

01

Definição do Problema e Escopo

Identificação e formalização do problema de gestão manual de pedidos. Delimitação do escopo para evitar scope creep e manter o foco nos objetivos centrais do projeto.

02

Levantamento e Análise de Requisitos

Mapeamento dos perfis de usuário (Admin Master, Gerente e Representante) e coleta dos requisitos funcionais e não funcionais com base nas necessidades reais identificadas.

03

Modelagem com Diagramas UML

Elaboração do Diagrama de Casos de Uso e do Diagrama de Classes para representar graficamente a estrutura e o comportamento do sistema antes da implementação.

04

Implementação Backend e Frontend

Desenvolvimento do backend em Django (lógica de negócio, controle de permissões, integração com banco de dados) e do frontend responsivo com Bootstrap 5.

05

Testes e Validação

Testes funcionais com verificação de aderência aos requisitos, testes de usabilidade e validação em quatro empresas com operação real de representantes comerciais.

06

Implantação na Google Cloud

Deploy da aplicação em infraestrutura de nuvem com alta disponibilidade, garantindo acesso remoto ao sistema para representantes e gestores em qualquer localização.
