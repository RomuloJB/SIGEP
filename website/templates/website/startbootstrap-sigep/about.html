Descricao do projeto

O presente trabalho propõe o desenvolvimento do Sistema Integrado de Gestão de Pedidos (SIGEP), uma solução tecnológica web, com telas responsivas, destinada à gestão estruturada de pedidos comerciais entre representantes de vendas e empresas. O sistema visa substituir processos manuais e informais de registro de pedidos por uma solução informatizada que contemple:

  • Cadastro de empresas, usuários e produtos;
  • Registro e gerenciamento de pedidos de entrada e saída;
  • Controle automático de estoque;
  • Controle de permissões por perfil de usuário;
  • Registro do ciclo de vida do pedido;
  • Notificações automatizadas por e-mail.

O projeto será desenvolvido utilizando a linguagem Python com o framework Django no backend, banco de dados relacional.
Trata-se de uma pesquisa aplicada com desenvolvimento tecnológico, focada na construção e validação de um sistema computacional para resolver um problema real de gestão comercial.
